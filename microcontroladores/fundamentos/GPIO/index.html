GPIOS

1. CONCEPTO Y ARQUITECTURA DE UN GPIO

Un GPIO (General Purpose Input/Output, entrada/salida de propósito general) es un pin de señal digital cuya función puede configurarse según las necesidades del sistema. No tiene una función fija: el programador o diseñador determina su utilización mediante la configuración del microcontrolador.

El término propósito general hace referencia precisamente a esta flexibilidad. Un GPIO puede configurarse para trabajar con diferentes tipos de señales digitales y, dependiendo del microcontrolador, también puede estar asociado a funciones analógicas o a diferentes periféricos internos.

1.1. Estructura interna y selección de función

Cada pin de un puerto GPIO está conectado a un circuito interno de interfaz configurable. La conexión entre este circuito interno y el circuito externo se realiza mediante un pin o pad.

El bloque denominado selección de función (function select) permite determinar qué función interna estará conectada al pin. De esta manera, un mismo pin físico puede utilizarse como GPIO o, si el microcontrolador lo permite, como conexión de diferentes periféricos.

Entre las funciones que pueden encontrarse en un pin están:

  • Entrada GPIO.
  • Salida GPIO.
  • Entrada analógica para un ADC.
  • Señales de comunicación, como UART, SPI o I²C.
  • Señales generadas por temporizadores o PWM.

Las características del pin se configuran mediante registros de control. Estos registros permiten seleccionar la dirección del pin, su función y otras propiedades eléctricas disponibles en el microcontrolador.

Este enfoque permite que un número relativamente pequeño de pines pueda desempeñar una amplia variedad de funciones. El resultado es un diseño más flexible y, en muchos casos, un menor número de conexiones físicas.

1.2. GPIO como entrada y como salida

Cuando un GPIO se configura como entrada, el circuito interno permite que el microcontrolador detecte el nivel de tensión presente en el pin. El programa puede leer ese estado e interpretarlo como un nivel lógico.

Cuando se configura como salida, el programa puede establecer el estado lógico del pin. En una salida digital convencional existen dos estados:

  • 0 lógico: nivel bajo.
  • 1 lógico: nivel alto.

Por tanto, un GPIO permite establecer una comunicación básica entre el software que se ejecuta en el microcontrolador y los circuitos externos conectados a sus pines.

También pueden existir rutas analógicas asociadas a determinados pines. Estas permiten conectar una señal externa con bloques analógicos internos, como un convertidor analógico-digital (ADC), siempre que el microcontrolador disponga de esta función.

2. NIVELES LÓGICOS Y CARACTERÍSTICAS ELÉCTRICAS

En una aplicación real, un GPIO no solamente representa información mediante los valores 0 y 1. También trabaja con niveles de tensión y corriente que deben respetarse para garantizar el funcionamiento correcto y evitar daños en el microcontrolador.

2.1. VDD, niveles lógicos y conversión de tensión

Normalmente, un microcontrolador utiliza una tensión de alimentación fija denominada VDD. En una salida digital, el nivel bajo se encuentra próximo a 0 V, mientras que el nivel alto está relacionado con la tensión de alimentación del circuito.

Hasta hace algunos años era habitual encontrar microcontroladores alimentados con aproximadamente 5 V. Sin embargo, los procesadores y microcontroladores actuales de bajo consumo pueden trabajar con tensiones mucho menores, llegando en determinados dispositivos hasta aproximadamente 1,8 V.

Esta reducción de la tensión de alimentación puede disminuir el consumo de energía, pero también puede provocar problemas de compatibilidad cuando se conectan dispositivos que trabajan con diferentes niveles lógicos.

Por ejemplo, si un microcontrolador trabaja con lógica de 1,8 V y otro circuito necesita señales de 3,3 V, puede ser necesario utilizar un convertidor de niveles lógicos (level converter) para adaptar las señales.

Por esta razón, no debe asumirse que un 1 lógico equivale siempre a 5 V. Los niveles eléctricos exactos dependen del dispositivo y deben consultarse en su documentación técnica.

2.2. GPIO como controlador de circuitos externos

En aplicaciones reales, un GPIO puede utilizarse para controlar un interruptor electrónico, por ejemplo un transistor, que permita habilitar o deshabilitar la alimentación de otro componente.

Esta solución es especialmente útil cuando la carga necesita más corriente de la que puede proporcionar directamente un GPIO. El pin controla la entrada del transistor y este se encarga de manejar la corriente de la carga.

Es importante recordar que un GPIO tiene límites de corriente. La corriente máxima por pin y la corriente total permitida para el microcontrolador deben consultarse siempre en el datasheet.

2.3. Más de dos niveles: señales analógicas y PWM

Una salida GPIO digital convencional solo proporciona dos niveles lógicos. Si una aplicación necesita representar más de dos niveles, debe utilizarse otro mecanismo.

Una posibilidad es utilizar una entrada o salida analógica, cuando el microcontrolador dispone de ella. Otra posibilidad es utilizar PWM (Pulse Width Modulation, modulación por ancho de pulso).

En PWM, la señal sigue alternando entre nivel bajo y nivel alto, pero se modifica el tiempo durante el cual permanece en cada estado. El porcentaje de tiempo que permanece en nivel alto se denomina ciclo de trabajo (duty cycle).

Por tanto, PWM no convierte directamente al GPIO en una salida analógica. Sigue siendo una señal digital, pero su comportamiento temporal permite obtener determinados valores medios cuando se utiliza con el circuito apropiado.

3. APLICACIÓN PRÁCTICA: CONTROLAR DOS LED MEDIANTE GPIO

Para comprender el funcionamiento de los GPIO podemos considerar un circuito en el que un interruptor determina cuál de dos LED debe encenderse.

El circuito utiliza un GPIO como entrada para leer el interruptor y otros dos GPIO como salidas para controlar los LED rojo y azul.

3.1. Funcionamiento del circuito

El programa lee el estado de la entrada y determina si la señal corresponde a un 0 o a un 1. Dependiendo del estado detectado, establece las salidas de los GPIO para encender uno u otro LED.

El funcionamiento puede resumirse de la siguiente manera:

Interruptor → GPIO de entrada → programa → GPIO de salida → LED

En una posición del interruptor, el procesador enciende el LED rojo. En la otra posición, enciende el LED azul.

Este ejemplo representa uno de los principios fundamentales de los sistemas embebidos: una condición física externa se convierte en una señal digital, el software procesa esa información y posteriormente genera una acción sobre el mundo físico.

3.2. Resistencias limitadoras y ley de Ohm

Los LED necesitan una resistencia en serie para limitar la corriente. El valor de esta resistencia puede calcularse mediante la ley de Ohm utilizando:

R = (VDD − VLED) / ILED

Donde:

  • R es el valor de la resistencia que se desea calcular.
  • VDD es la tensión de alimentación.
  • VLED es la tensión necesaria para el LED, denominada tensión directa.
  • ILED es la corriente que se desea hacer circular por el LED.

Para este ejemplo se considera una alimentación de 3 V y una corriente de 4 mA, equivalente a 0,004 A.

3.3. Cálculo de las resistencias para los LED

Para el LED rojo se considera una tensión directa aproximada de 1,8 V:

R = (3 V − 1,8 V) / 0,004 A = 300 Ω

Por tanto, el valor calculado para el LED rojo es de 300 Ω.

Para el LED azul se considera una tensión directa aproximada de 2,7 V:

R = (3 V − 2,7 V) / 0,004 A = 75 Ω

Por tanto, el valor calculado para el LED azul es de 75 Ω.

Los valores son diferentes porque los dos LED presentan diferentes tensiones directas. Aunque ambos se alimentan con 3 V y se desea una corriente de 4 mA, la tensión que debe absorber la resistencia no es la misma.

Para el LED rojo:

3 V − 1,8 V = 1,2 V

Para el LED azul:

3 V − 2,7 V = 0,3 V

En un diseño real, los valores deben verificarse utilizando las características eléctricas reales del LED y del microcontrolador, además de las tolerancias de los componentes y los valores comerciales disponibles.

4. ENTRADAS GPIO Y RESISTENCIAS PULL-UP Y PULL-DOWN

Cuando se conecta un interruptor a una entrada GPIO es necesario garantizar que el pin tenga siempre un nivel lógico definido. De lo contrario, cuando el interruptor esté abierto, la entrada puede quedar en un estado denominado flotante (floating).

4.1. El problema de una entrada flotante

Una entrada flotante no está conectada de forma definida ni a VDD ni a GND. Debido a la alta impedancia de una entrada digital, pequeñas perturbaciones eléctricas o ruido pueden provocar que el circuito interprete el pin unas veces como un 0 y otras como un 1.

En consecuencia, el programa no puede determinar de forma fiable el estado del interruptor.

Las resistencias pull-up y pull-down solucionan este problema estableciendo un estado predeterminado conocido.

4.2. Pull-up y pull-down

Una resistencia pull-up conecta la entrada, a través de una resistencia, hacia VDD. Cuando el interruptor está abierto, la entrada queda normalmente en nivel alto.

Una resistencia pull-down conecta la entrada, a través de una resistencia, hacia GND. Cuando el interruptor está abierto, la entrada queda normalmente en nivel bajo.

La resistencia tiene además la función de limitar la corriente cuando el interruptor establece una conexión directa hacia el nivel contrario.

4.3. Funcionamiento de SW1 con configuración pull-up

En el circuito planteado, queremos que el interruptor SW1 (IN) lleve el pin de entrada a GND cuando se accione. Para ello utilizamos una configuración pull-up.

Cuando SW1 está abierto, la resistencia mantiene la entrada conectada hacia VDD. El GPIO interpreta entonces un 1 lógico.

Cuando SW1 está cerrado, la entrada queda conectada a GND. El GPIO interpreta entonces un 0 lógico.

Estado de SW1 Nivel del GPIO Estado de la entrada
Abierto 1 VDD mediante la resistencia pull-up
Cerrado 0 Conectado a GND

Esta configuración es muy utilizada con pulsadores e interruptores porque garantiza un nivel lógico conocido cuando el interruptor no está accionado.

5. CONSIDERACIONES PRÁCTICAS Y VISIÓN DE SISTEMA

El GPIO es uno de los mecanismos fundamentales mediante los cuales un microcontrolador interactúa con el mundo exterior. Sin embargo, utilizarlo correctamente requiere tener en cuenta tanto su configuración digital como sus características eléctricas.

5.1. Aspectos que deben comprobarse en un diseño

No todos los GPIO de un microcontrolador son necesariamente iguales. Algunos pueden disponer de funciones alternativas, ADC, PWM, interrupciones u otras características que no están disponibles en todos los pines.

Por esta razón, antes de utilizar un pin debe consultarse el datasheet y, cuando sea necesario, el manual de referencia del microcontrolador.

También deben comprobarse:

  • La tensión de alimentación y los niveles lógicos.
  • Los límites de corriente del pin.
  • La corriente total permitida por el microcontrolador.
  • Las funciones alternativas disponibles.
  • La compatibilidad eléctrica con los dispositivos externos.
  • La necesidad de resistencias pull-up o pull-down.
  • La necesidad de un convertidor de niveles lógicos.

5.2. Del GPIO al sistema embebido

El ejemplo del interruptor y los LED permite observar el funcionamiento básico de un sistema embebido completo.

Primero, un dispositivo físico genera una condición eléctrica. El GPIO configurado como entrada detecta esa condición y la convierte en información digital para el procesador. El programa interpreta esa información y toma una decisión. Finalmente, uno o varios GPIO de salida generan las señales necesarias para controlar otros componentes.

El proceso puede resumirse como:

Entrada física → GPIO → procesamiento del software → GPIO → acción física

Este principio se mantiene incluso en sistemas mucho más complejos. Un GPIO puede utilizarse para leer un pulsador, detectar el estado de un dispositivo, habilitar o deshabilitar un circuito, controlar un transistor, activar una etapa de potencia o participar en la interfaz con un periférico.

5.3. Idea fundamental

Un GPIO no debe entenderse únicamente como un pin que puede ponerse a 0 o a 1. Es una interfaz configurable entre el microcontrolador y el circuito externo.

Comprender su arquitectura, sus niveles eléctricos, sus límites de corriente, la selección de funciones y el uso correcto de resistencias de polarización constituye una base fundamental para trabajar con microcontroladores y diseñar sistemas embebidos fiables.
