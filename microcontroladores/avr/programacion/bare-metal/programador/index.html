CONEXiÓN DEL PROGRAMADOR ISP USBasp

INTRODUCCIÓN

La carga del firmaware en el microcontrolador y la depuración la haremos a través del programador ISP USBasp.

USBasp es un programador de hardware libre y de bajo costo para microcontroladores Atmel AVR. Consta simplemente de un ATMega88 o un ATMega8 y un par de componentes pasivos. El programador utiliza un controlador USB basado únicamente en firmware; para Linux y Mac Os no se necesita ningún controlador USB especial.

USBasp se conecta a la estación de trabajo por USB y al microcontrolador por el bus de comunicación serial SPI (interfaz perifericos serial). El Bus SPI (del inglés Serial Peripheral Interface) es un estándar de comunicaciones, usado principalmente para la transferencia de información entre circuitos integrados. El bus SPI es un bus de comunicación en serie, lo que significa que los datos se transfieren bit a bit a través de un único canal de comunicación.

El software de programación o flasheo AVRDUDE, que utilizamos en este sitio, es compatible con USBasp desde la versión 5.2.

1. CONEXIÓN DEL USBasp a la PC

El ATmega puede programarse mediante ISP (In-System Programming), es decir sin necesidad de retirar el microcontrolador del circuito. El USBasp permite realizar esta operación desde la estación de trabajo.

Después de conectar el USBasp al puerto USB de la Raspberry pi 5 podemos comprobar que el sistema lo reconoce con el comando lsusb: 

lsusb
Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
Bus 001 Device 002: ID 16c0:05dc Van Ooijen Technische Informatica shared ID for use with libusb
Bus 002 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub
Bus 003 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
Bus 003 Device 002: ID 1ea7:0066 SHARKOON Technologies GmbH [Mediatrack Edge Mini Keyboard]
Bus 004 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub

La salida muestra los 4 puertos USB disponibles en la estación de trabajo, 2 puertos 2.0 y 2 puertos 3.0:

  • Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
  • Bus 002 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub
  • Bus 003 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
  • Bus 004 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub

Además muestra que el sistema reconoce 2 dispositivos conectados por USB

  • Bus 001 Device 002: ID 16c0:05dc Van Ooijen Technische Informatica shared ID for use with libusb
  • Bus 003 Device 002: ID 1ea7:0066 SHARKOON Technologies GmbH [Mediatrack Edge Mini Keyboard]

    • La segunda etiqueta corresponde a un teclado inalámbrico y la primera etiqueta corresponde al USBasp.

    La identificación del USBasp es 16c0:05dc, que corresponde a Van Ooijen Technische Informatica shared ID for use with libusb. Esto ocurre porque el creador del USBasp utilizó el identificador de fabricante (Vendor ID) sublicenciado gratuitamente por el ingeniero holandés Wouter van Ooijen para apoyar proyectos de código abierto y evitar los costosos pagos de registro ante la USB-IF. De este modo, la base de datos de Linux lee dicho código asignado y reconoce la firma del licenciante, confirmando así que el programador está correctamente reconocido por el sistema operativo y listo para interactuar con herramientas como AVRDUDE.

    Podemos comprobar que el USBasp está correctamente conectado y reconocido por el sistema operativo con el siguiente comando, ponemos también a contnuación la salida del comando: 

    
avrdude -c usbasp -p m88p

avrdude: AVR device initialized and ready to accept instructions
avrdude: device signature = 0x1e940b (probably m168p)

avrdude done.  Thank you.

    2. CONEXIÓN DEL USBasp CON EL MICROCONTROLADOR

    La conexión del USBasp con el microcontrolador se realiza a través de un conector de 10 pines, que se conecta a los respectivos pines del microcontrolador. La conexión utiliza principalmente seis señales: MISO, MOSI, SCK, RESET, VCC y GND.

    Para programar un dispositivo de la serie ATmega48A/PA/88A/PA/168A/PA/328/P, mediante la interfaz ISP (In-System Programming) utilizando un USBasp, debes conectar seis señales entre el programador y el microcontrolador.

    Señal ISP Pin del ATmega48A/PA/88A/PA/168A/PA/328/P Descripción
    MOSI 17 (PB3) Datos del programador hacia el microcontrolador.
    MISO 18 (PB4) Datos del microcontrolador hacia el programador.
    SCK 19 (PB5) Señal de reloj de la programación SPI.
    RESET 1 (PC6/RESET) Coloca el microcontrolador en modo de programación.
    VCC 7 y 20 Alimentación (+5 V o +3.3 V, según el sistema).
    GND 8 y 22 Tierra (masa).
