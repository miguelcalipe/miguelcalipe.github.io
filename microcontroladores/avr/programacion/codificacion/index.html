FIRMWARE PARA MICROCONTROLADORES AVR

1. ESCRIBIR EL PROGRAMA

El primer paso consiste en escribir el programa que ejecutará el microcontrolador. En este artículo utilizaremos el lenguaje C, ya que es el lenguaje más utilizado para desarrollar aplicaciones sobre microcontroladores AVR. Aunque existen otros lenguajes y herramientas que permiten programarlos, prácticamente toda la documentación, ejemplos y bibliotecas oficiales están pensadas para C.

El programa lo guardaremos en un archivo de código fuente cuya extensión es .c. Este archivo almacena el código escrito por el programador en un formato de texto plano. Dicho de otra manera, es un archivo legible por una persona, pero todavía incomprensible para el microcontrolador. Más adelante será el compilador quien se encargue de traducirlo al lenguaje máquina.

Para escribir el programa puedes utilizar cualquier editor de texto. En GNU/Linux existen muchas alternativas, como nano, vim, emacs, Visual Studio Code, Geany o incluso un editor gráfico sencillo como Gedit. En este artículo utilizaremos nano, ya que está instalado por defecto en la mayoría de distribuciones y resulta muy fácil de usar desde la línea de comandos.

Antes de crear el archivo conviene abrir una terminal y situarse en la carpeta donde deseamos guardar el proyecto. Puedes crear una carpeta específica para tus programas AVR o utilizar cualquier directorio de trabajo. Por ejemplo: 

mkdir avr && cd avr

Todos los archivos que vayamos creando durante el desarrollo (código fuente, archivos objeto, ejecutables y archivos para programar el microcontrolador) se generarán dentro de esta carpeta que hemos denominado avr (puede ser cualquier otro nombre). Esto permite mantener todos los archivos relacionados con el proyecto en un solo lugar, lo que facilita mantener organizado el proyecto.

Una vez dentro del directorio de trabajo, creamos un nuevo archivo llamado blink.c ejecutando: 

nano blink.c

Al hacerlo, nano abrirá un archivo nuevo. Si el archivo ya existía, simplemente lo abrirá para editarlo.

Escribimos entonces el siguiente programa: 


    #include <avr/io.h>
    #include <util/delay.h>

    int main(void)
    {
        DDRB |= (1 << DDB1);      // PB1 como salida

        while (1)
        {
            PORTB ^= (1 << PORTB1);
            _delay_ms(300);
        }
    }

Una vez terminado, debemos guardar el archivo. En nano se hace presionando Ctrl + O (de Write Out). El editor mostrará el nombre del archivo, en este caso blink.c. Simplemente presionamos Enter para confirmar. Después salimos del editor con Ctrl + X.

El nombre del archivo puede ser cualquiera siempre que termine con la extensión .c. Por ejemplo, led.c, contador.c, prueba.c o main.c. En este artículo utilizaremos el nombre blink.c porque el programa hace parpadear un LED.

En este punto únicamente hemos creado el código fuente. Es decir, un archivo de texto que contiene instrucciones escritas en lenguaje C. Todavía no existe un programa que el microcontrolador pueda ejecutar. En el siguiente paso utilizaremos el compilador avr-gcc, que traducirá este código fuente a lenguaje máquina para el un dispositivo de la serie .
