LOS TRES REGISTROS FUNDAMENTALES DE ENTRADA Y SALIDA (GPIO)

1. LOS REGISTROS GPIO

En la arquitectura de los microcontroladores AVR de 8 bits, los pines físicos de conexión con el mundo exterior se agrupan en bloques lógicos denominados PUERTOS. Un puerto comprende un banco de hasta 8 pines físicos de Entrada/Salida (E/S o GPIO), identificados con letras según el periférico del chip por ejemplo, Puerto A (PA), Puerto B (PB), Puerto C (PC), Puerto D (PD).

Para controlar de forma integral el comportamiento eléctrico, la dirección de la corriente y el nivel de voltaje de cada pin, el hardware del AVR destina tres registros dedicados de 8 bits por cada puerto:

Registro Nombre Oficial Función Técnica Principal
DDRx Data-Direction Register Controla la dirección del flujo de datos del pin: define si opera como Entrada (Input) o como Salida (Output).
PORTx Port x Data Register En modo salida: controla el voltaje emitido (1 = VCC, 0 = GND). En modo entrada: activa o desactiva la resistencia pull-up interna del pin.
PINx Port x Input Pins Address Registro de solo lectura que refleja el voltaje digital real aplicado externamente en las patillas. En AVRs modernos, escribir un 1 conmuta (toggle) el estado del registro PORTx.

Tomando como ejemplo práctico el Puerto B, sus tres registros asociados son DDRB, PORTB y PINB. La arquitectura mantiene una correspondencia unívoca uno a uno entre cada bit de un registro de 8 bits y un pin físico del circuito integrado:

Bit del Registro:   7    6    5    4    3    2    1    0
Pin Físico Chip:   PB7  PB6  PB5  PB4  PB3  PB2  PB1  PB0

2. ASIGNACIÓN DE DIRECCIÓN (DDRx)

Para determinar la orientación lógica de la corriente en un pin digital (si lee una señal exterior o maneja una carga), el programador modifica el Registro de Dirección de Datos (DDRx).

2.1. Configuración de Estados Lógicos de Dirección

  • Asignar Salida (Output): Se escribe un uno (1) en el bit correspondiente del registro DDRx. Esto habilita los transistores de potencia internos para conmutar corriente hacia el exterior.
  • Asignar Entrada (Input): Por defecto, tras un evento de encendido o reinicio por hardware (Reset), el sistema establece todos los bits de DDRx en cero (0). Esto coloca los pines automáticamente en modo entrada como medida de seguridad eléctrica.

2.2. Análisis de un Ejemplo Práctico de Asignación Directa

Consideremos la ejecución del siguiente comando en lenguaje C:

DDRB = 0b00000010;

Esta instrucción escribe un patrón de 8 bits directamente sobre el registro DDRB. El mapeo de bits a nivel de hardware se interpreta de la siguiente manera:

Pin Físico:     PB7  PB6  PB5  PB4  PB3  PB2  PB1  PB0
Valor en DDRB:   0    0    0    0    0    0    1    0

Al reescribir el registro por completo, la circuitería interna del microcontrolador aplica de inmediato el siguiente estado eléctrico individual en sus terminales:

Pin Físico Estado de Dirección Configurado
PB1 SALIDA (Output)
PB0, PB2–PB7 ENTRADA (Input)

2.3. Inconvenientes de la Asignación Directa

La asignación directa mediante literales binarios (DDRB = 0b00000010;) borra el estado previo de los 8 bits del puerto. En el desarrollo industrial de firmware, se prefiere modificar un único pin sin alterar la configuración de los pines vecinos utilizando operadores lógicos a nivel de bits (bitwise operations):

DDRB |= (1 << PB1); // Configura PB1 como salida de forma no destructiva

3. CONTROL DEL VOLTAJE Y RESISTENCIAS INTERNAS (PORTx)

Una vez definida la dirección de los pines a través del registro DDRx, el registro PORTx asume una doble funcionalidad según la configuración eléctrica establecida.

3.1. Comportamiento en Modo Salida (DDRx = 1)

Cuando un bit en DDRx está configurado como salida, el bit equivalente en PORTx controla el driver de salida de voltaje activo:

  • PORTx = 1 (Lógica Alta / High): El pin interno conmuta a VCC (usualmente 5 V o 3.3 V segun el circuito), inyectando voltaje y actuando como una fuente de corriente (current source).
  • PORTx = 0 (Lógica Baja / Low): El pin interno conmuta a masa o tierra (GND / 0 V), actuando como un drena corriente (current sink).

3.2. Comportamiento en Modo Entrada (DDRx = 0)

Cuando un bit en DDRx está configurado como entrada, el bit equivalente en PORTx gobierna el acoplamiento de resistencias internas:

  • PORTx = 1 (Pull-Up Activa): Conecta una resistencia de elevación interna (pull-up resistor) de entre 20 kΩ y 50 kΩ aproximadamente desde el pin hacia VCC. Esto garantiza que el pin lea un nivel '1' estable en reposo y evita lecturas erráticas sin consumir corriente apreciable.
  • PORTx = 0 (Alta Impedancia / Hi-Z): Desconecta la resistencia interna. El pin queda flotando eléctricamente, presentando una impedancia extremadamente alta (ideal para medir circuitos analógicos o buses externos sin alterar la señal).

4. LECTURA DEL ESTADO E INVERSIÓN POR HARDWARE (PINx)

El registro PINx se utiliza para conocer el estado lógico de los pines configurados como entradas.

A diferencia de DDRx y PORTx, el registro PINx interactúa directamente con los búferes de lectura conectados a la patilla metálica del integrado.

4.1. Muestreo de Lectura Digital

Para inspeccionar las condiciones eléctricas del circuito exterior (por ejemplo, detectar la pulsación de un botón o la señal de un sensor), el código debe leer el registro PINx. La lectura de este registro no consulta el valor guardado en la memoria RAM, sino la tensión real presente en el pin físico.

if (PINB & (1 << PB0)) {
    // Código a ejecutar si el voltaje medido en el pin PB0 es ALTO (VCC)
}

4.2. Conmutación Ultraeficiente por Hardware (Toggle Hardware)

En los microcontroladores AVR modernos, el registro PINx posee un mecanismo físico especial: si el firmware escribe un valor 1 lógico en cualquiera de sus bits mientras el pin está configurado como salida, el hardware del AVR invierte automáticamente (toggle) el estado almacenado en el registro PORTx.

Esta operación pasa un pin de 0 V a 5 V (o viceversa) en un solo ciclo de reloj de la CPU, eliminando la necesidad de leer, modificar y reescribir manualmente por software el registro PORTx.

PINB = (1 << PB1); // Conmuta el estado de PB1 instantáneamente por hardware

5. MATRIZ UNIFICADA DE CONFIGURACIÓN DE PINES (GPIO)

Combinando las interacciones entre los registros DDRx, PORTx y PINx, se deriva la matriz absoluta de estados operacionales para cualquier pin individual (PBn) dentro de la arquitectura AVR:

Bit DDRx Bit PORTx Bit PINx (PBn) Estado Físico y Comportamiento Electrónico
0 0 Lectura real (0 o 1) Entrada en Alta Impedancia (Hi-Z): El pin flota eléctricamente. El estado medido en PINx depende exclusivamente de la tensión aplicada por el circuito exterior.
0 1 Lectura real (1 por defecto) Entrada con Resistencia Pull-Up Activa: La resistencia interna mantiene el pin ligado a VCC. PINx lee 1 en reposo y 0 si un pulsador externo lo deriva a masa (GND).
1 0 0 (ó 1 tras Toggle) Salida Lógica BAJA (GND / 0 V): Conduce tierra de forma activa. Si se escribe un 1 en el bit correspondiente de PINx, el pin conmuta a 5 V por hardware.
1 1 1 (ó 0 tras Toggle) Salida Lógica ALTA (VCC / 5 V): Inyecta voltaje activo. Si se escribe un 1 en el bit correspondiente de PINx, el pin conmuta a 0 V por hardware.
