1. TIPOGRAFÍA, ENCABEZADOS Y LISTAS

Este bloque demuestra el comportamiento estándar de un contenedor <section> dentro de body.articulo main. Los párrafos aplican automáticamente text-align: justify; y un espaciado vertical de 0.8rem para facilitar la lectura de documentación técnica extensa.

1.1. Encabezado de Nivel 3 (<h3>) y Listas

El estilo h3 utiliza var(--secondary-color) para jerarquizar subtemas dentro de una misma sección:

  • Lista no ordenada (<ul>): Ideal para enumerar características de hardware, pines o periféricos.
  • Margen inferior (li): Cada elemento conserva margin-bottom: 0.5rem para evitar apelotonamiento visual.
  1. Lista ordenada (<ol>): Paso 1 para configurar un registro (ej. habilitar el bit CLKPCE).
  2. Secuencia crítica: Paso 2 dentro de los siguientes 4 ciclos de reloj.

2. CAJAS DE FÓRMULAS Y ALERTAS

Utilizadas para resaltar ecuaciones matemáticas (renderizadas con MathJax) y advertencias críticas de hardware o programación.

2.1. Contenedor de Fórmulas (.formula-box)

Cálculo de capacitancia externa para cristal de 32.768 kHz:

$$C = 2 \cdot C_L - C_S$$

Donde $C_L$ es la capacitancia de carga nominal del cristal y $C_S$ la capacitancia parásita de las pistas del PCB.

2.2. Caja de Alerta o Precaución (.alert-box)

⚠️ Advertencia de Hardware (Fusibles AVR): Nunca deshabilites el fusible SPIEN ni programes RSTDISBL si vas a seguir utilizando un programador ISP estándar (como USBasp), ya que perderás el acceso de programación serial al microcontrolador.

3. BLOQUES DE CÓDIGO Y CÓDIGO EN LÍNEA

3.1. Código en línea (:not(pre) > code)

Cuando mencionas registros como DDRB, PORTB, macros como _BV(PB0) o comandos de terminal como avrdude -c usbasp -p m328p dentro de un párrafo, se estilizan automáticamente con fondo azul suave y tipografía monoespaciada.

3.2. Bloque de código completo (<pre><code>)

Soporta desplazamiento horizontal automático (overflow-x: auto) sin romper las líneas en pantallas móviles: 

#include <avr/io.h>
#include <util/delay.h>

int main(void) {
    // Configurar PB0 (Pin 14 DIP-28) como salida
    DDRB |= (1 << DDB0);

    while (1) {
        PORTB ^= (1 << PORTB0); // Conmutar estado lógico del pin
        _delay_ms(500);
    }
    return 0;
}

4. TABLAS RESPONSIVAS (.table-container)

Envolver las etiquetas <table> dentro de un <div class="table-container"> garantiza el scroll horizontal en dispositivos estrechos y aplica filas alternas (zebra striping).

Ejemplo: Estructura del Byte Low Fuse (lfuse) en ATmega328P
Bit Nombre Valor Fábrica Función Principal
7 CKDIV8 0 (Programado) Divide el reloj del sistema entre 8 al arrancar.
6 CKOUT 1 (No programado) Habilita la salida de reloj por el pin PB0/CLKO.
5..4 SUT1..0 10 Selecciona el tiempo de espera (Start-up Time).
3..0 CKSEL3..0 0010 Selecciona el Oscilador RC Interno Calibrado de 8 MHz.
Nota: En la arquitectura AVR, un bit de fusible en 0 significa programado/activo.

5. DISTRIBUCIÓN MULTICOLUMNA

Clases utilitarias basadas en CSS Multi-column Layout. Todas colapsan automáticamente a 1 columna en pantallas menores a 768px.

5.1. Dos Columnas (.dos-columnas)

Columna 1 (Arquitectura Harvard): Separa físicamente los buses y memorias de programa (Flash) y datos (SRAM), permitiendo leer la siguiente instrucción mientras se ejecuta la actual.

Columna 2 (Registros GPR): El núcleo AVR cuenta con 32 registros de propósito general de 8 bits (R0 a R31) conectados directamente a la ALU para ejecución en un solo ciclo.

5.2. Tres Columnas (.tres-columnas)

1. Preprocesamiento: Resolución de directivas #include y #define mediante avr-gcc -E.

2. Compilación y Ensamblado: Traducción a código objeto relocalizable (.o) específico para la arquitectura.

3. Enlazado (Linking): Generación del ejecutable .elf y extracción del archivo .hex con avr-objcopy.

5.3. Cuatro Columnas (.cuatro-columnas)

Registro DDRx: Data Direction Register (Configura entrada/salida).

Registro PORTx: Data Register (Escribe nivel alto/bajo o activa pull-up).

Registro PINx: Input Pins Address (Lee el estado físico del pin).

Bit PUD: Pull-up Disable en el registro MCUCR.

5.4. Cinco Columnas (.cinco-columnas)

clkCPU: Núcleo y ALU.

clkI/O: Timers, UART, SPI.

clkFLASH: Bus de memoria Flash.

clkASY: Timer2 asíncrono.

clkADC: Conversor analógico.
